# Database for InteFL Framework

___

.env variables:

* EXPERIMENT_DB_MODE: `direct` for direct access by db url, `server` for access through HTTP server, `neon` to send to neon cloud DBMS
* EXPERIMENT_DB_NAME
* EXPERIMENT_DB_PASSWORD
* EXPERIMENT_DB_HOST
* EXPERIMENT_DB_PORT
* EXPERIMENT_DB_USER
* FULL_AUTHOR_NAME: name of the experiment author
* AUTHOR_EMAIL
* EXPERIMENT_SERVER_URL: host where experiment server is located
* EXPERIMENT_SERVER_TOKEN: access token provided by admin
* EXPERIMENT_SERVER_PORT
